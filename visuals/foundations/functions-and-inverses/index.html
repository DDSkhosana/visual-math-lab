The 12 Specification Styles

A function f: X → Y is formally a relation f ⊆ X × Y satisfying totality (∀x ∈ X) and uniqueness (∃!y ∈ Y). It can be specified in 12 distinct mathematical styles:

1. Set of Ordered Pairs: f = {(1, a), (2, b), (3, c)}
2. Table Form: Input column paired directly with output column.
3. Explicit Formula: f(x) = 2x + 1 with specified domain.
4. Piecewise Formula: Branching definitions on partitioned subdomains.
5. Implicit Equation: F(x, y) = 0 (requires implicit function theorem).
6. Recursive / Inductive: Base case + induction step (e.g. factorial).
7. Algorithmic / Program: Deterministic halting Turing computation.
8. Lambda Abstraction: λx. x² + 1 in pure lambda calculus.
9. Graphical Curve: 2D plot satisfying the vertical line test.
10. Categorical Arrow: Morphism making commutative diagrams commute.
11. Characteristic Indicator: χ_A(x) ∈ {0, 1} encoding subset membership.
12. Limit / Series / Integral: Convergent sequence of approximating maps.
